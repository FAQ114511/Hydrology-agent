[2024-05-10 | XIANGJIANG | 黄色预警 | logged]

DECISION:
**预警等级**: 黄色预警

**行动摘要**: 对 XIANGJIANG 维持黄色预警管理，执行加强监测预警：降雨期间水位、流量逐小时报汛，非降雨时段至少每6小时一报；对已渗水堤段落实专人24小时值守，每日至少2次全面巡查，并预置抢险物料、转移路线和安置点。重点盯防05-11降雨峰值及上游来水滞后窗口。一旦实测降雨达到或接近70 mm、水位/流量出现明显二次加速或逼近警戒水位、堤防险情恶化，立即上调至橙色或红色预警。

**研判结论**: 综合三方辩论，XIANGJIANG 当前风险明显，但不足以支撑橙色或红色预警，也不应退回蓝色，维持黄色预警最符合证据边界。

支持维持黄色、不升橙红的证据链是：第一，水文缺少关键锚定阈值。各分析师均承认，目前没有警戒水位、保证水位和行洪能力对应临界水位，35.533 m 水位与 3316.6 m³/s 流量虽处于观测期高位，但无法锚定到橙/红等级；在防汛预警中，橙/红通常需与超警、超保或相应流量阈值挂钩，缺此依据时强行升级会透支预警权威。第二，水文过程为高位缓涨而非急涨。05-06 的大幅上涨跨越数据缺口，单日涨幅可能被高估；05-07 以来日涨幅放缓，水位日涨约 0.094 m，流量24小时仅增加 9.6 m³/s，未出现激进派所称的“二次加速”。第三，70 mm 降雨仍是05-11的预报值，而非已落地实况，不能把未来概率事件当作已经发生的致灾事实。第四，土壤饱和度92%、水库可用调蓄仅20 mm、行洪能力占用88% 属于承灾环境脆弱性指标，堤防轻微渗水是已出现险情，但这些状态量还不能单独证明将发生超警洪水，更适合作为强化准备和设置升级条件的依据。第五，社会影响数据（1800人受影响、420人转移、5处道路管控、2所学校停课、210公顷农田受灾）置信度为 medium，且更反映灾害响应与脆弱性，不宜单独作为洪水预警升级的直接依据。

但同样不能退回蓝色常规监测。XIANGJIANG 确实处于05-06以来暴雨驱动的显著涨水过程，水位三日连涨、流量为观测期最高、7日雨量333.9 mm，叠加高土壤饱和度、低库容余量、行洪占用高、堤防已渗水以及社会影响非线性放大，风险明显偏高。激进派关于“环境余量小、容错率低”的判断成立：土壤饱和度92%意味着后续降雨产流效率高，库容余量20 mm意味着拦蓄能力有限，行洪余量不足12%，堤防渗水在高水位冲击下存在突变可能。因此，黄色预警下的执行标准应当上调，而非停留在一般强度。

在具体行动上，采纳中立派提出的“黄色等级、准橙色准备”：对已渗水堤段实行专人24小时值守并记录渗水变化，抢险物料前置到点；明确升级触发条件并置于待命状态，若05-11实测降雨达到或接近70 mm、水位日涨幅重新超过0.3 m、流量明显突破3400 m³/s、渗水扩大为渗透变形或转移需求显著增加，则立即升级；提前核定道路管控区和低洼高风险区的扩大转移名单并预通知到户，但不强制立即撤离；与水利工程调度部门确认上游水库是否泄洪及预泄安排，以消除调度信息缺失带来的不对称不确定性。

综上，当前证据支持“风险明显、证据不足以升橙/红、亦不能降蓝”的判断，黄色预警是平衡证据边界与防汛准备力度的最优选择，并保留快速升级余地。

**影响区域**: XIANGJIANG 站所在河段沿岸低洼区、已出现轻微渗水堤段及5处道路管控区域
